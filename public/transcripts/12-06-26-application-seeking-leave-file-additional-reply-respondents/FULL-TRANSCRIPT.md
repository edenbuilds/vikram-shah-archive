1. 已知 $a, b, c$ 为实数，且 $a^2 + b^2 = c^2$，求 $a, b, c$ 的大小关系。
2. 已知 $a, b, c$ 为实数，且 $a^2 + b^2 = c^2$，求 $a, b, c$ 的最小值。

**解：**

1. 由 $a^2 + b^2 = c^2$ 可得 $|a - b| = |c - a|$。因为 $a, b, c$ 为实数，所以 $a, b, c$ 的大小关系为 $a \geq b \geq c$。

2. 将 $a^2 + b^2 = c^2$ 展开，得到 $(a - b)^2 + (c - a)^2 = c^2$。即 $a^2 - 2ab + b^2 + c^2 - 2ac + a^2 = c^2$。整理后得到 $2(a - b)^2 = 0$。所以 $a - b = 0$，即 $a = b$。将 $a = b$ 代入 $a^2 + b^2 = c^2$ 中，得到 $2b^2 = c^2$。因此 $b = \frac{c}{2}$。综上所述，$a = b = \frac{c}{2}$。

3. 将 $a^2 + b^2 = c^2$ 展开，得到 $(a - b)^2 + (c - a)^2 = c^2$。即 $a^2 - 2ab + b^2 + c^2 - 2ac + a^2 = c^2$。整理后得到 $2(a - b)^2 = 0$。所以 $a - b = 0$，即 $a = b$。将 $a = b$ 代入 $a^2 + b^2 = c^2$ 中，得到 $2b^2 = c^2$。因此 $b = \frac{c}{2}$。综上所述，$a = b = \frac{c}{2}$。
